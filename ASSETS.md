# Asset origins and redistribution

Verified on **2026-09-20** for the first public source release, based on ShoreBreak
revision 23. All runtime assets are bundled in `public/`.

## Photographic textures — CC0-1.0

| Files | Original asset | Creator | Use |
| --- | --- | --- | --- |
| `public/assets/palms-r6/bark-*.webp` | [Palm Bark](https://polyhaven.com/a/palm_bark) | Charlotte Baglioni | Palm trunks |

[Poly Haven's asset license](https://polyhaven.com/license) explicitly permits
redistribution, modification, and commercial use under CC0. These textures remain
CC0; the project's MIT license does not replace their original license. The
license text is included in `licenses/CC0-1.0.txt`. Credits are retained as a courtesy.

The original 2K JPEGs inherited from Ashore/Jellys were identified by matching
**all six MD5 checksums** against Poly Haven's published file metadata:

- Bark color, OpenGL normal, and roughness: `palm_bark`.
- Stone color, OpenGL normal, and packed ARM: `rock_boulder_dry`.

The inherited file called `rock-rough.jpg` is actually the original **ARM map**
(ambient occlusion, roughness, metalness); roughness is in its green channel.
Renaming it did not change its source identity. The published WebP derivatives
retain this channel layout for the promenade.

Palm and promenade maps are 1024-pixel WebP derivatives. Coastal maps use
2048-pixel color and OpenGL normals with roughness packed into normal alpha.
The original coastal-material conversion notes remain in
`public/assets/coast-r8/CREDITS.txt`.

`docs/asset-provenance.json` records original download URLs, source checksum
matches, the conversion relationship, and SHA-256 hashes for every bundled
runtime asset. `npm run licenses:check` checks the bundled files against that
manifest; it does not independently make a legal determination.

## Procedural geometry and artwork — MIT

Palm geometry is generated by `tools/vendor/date-palm.js` and
`tools/vendor/ashore-leaf.js`, adapted from Christopher Canavan's Ashore/Jellys
projects. The generator and its baked `.bin` / `.bin.gz` outputs are included
under the project MIT license. These are modeled leaflets, fronds, and trunks,
not a downloaded palm model. Run `npm run bake:palms` to regenerate the geometry.

The coast, rocks, promenade, buildings, water meshes, procedural noise, foam,
and sky are generated by the included project code. The favicon is original
project SVG artwork, covered by MIT. The interface uses system fonts; there are
no bundled font files, audio tracks, stock videos, or external HDRI files.

## References versus assets

Real-world images and videos were consulted while developing the scene. They
are not redistributed in this repository, and their rights are not included in
the MIT release. Project names identify the lineage of the code and assets;
they do not imply third-party endorsement.
